# 资源文件目录

本目录存放小程序所需的图片和音频资源。

## 需要准备的资源文件

| 文件 | 说明 | 建议尺寸 |
|------|------|---------|
| `woodfish.png` | 木鱼敲击图片 | 400×400px, PNG透明背景 |
| `icon_woodfish.png` | 底部Tab图标（木鱼） | 81×81px, PNG |
| `icon_woodfish_active.png` | 底部Tab图标-选中态 | 81×81px, PNG |
| `icon_ranking.png` | 底部Tab图标（排行榜） | 81×81px, PNG |
| `icon_ranking_active.png` | 底部Tab图标-选中态 | 81×81px, PNG |
| `icon_my.png` | 底部Tab图标（我的） | 81×81px, PNG |
| `icon_my_active.png` | 底部Tab图标-选中态 | 81×81px, PNG |
| `share_cover.png` | 分享封面图 | 400×300px, JPG/PNG |

## 资源获取方式

### 1. 自制
- 使用 Figma / Sketch / Photoshop 自行设计
- 木鱼图片可用 AI 绘图工具生成

### 2. 免费图标库
- [iconfont](https://www.iconfont.cn/) - 阿里巴巴图标库
- [Flaticon](https://www.flaticon.com/) - 免费图标

### 3. 临时占位
开发阶段可使用纯色块代替，代码中已用 CSS 绘制的占位符替代。
