# 音频文件目录

## 需要准备的音效文件

| 文件 | 说明 | 建议 |
|------|------|------|
| `tap.mp3` | 木鱼敲击音效 | 100KB以内，短促清脆 |

## 音效获取方式

1. **免费音效网站**
   - [freesound.org](https://freesound.org/) - 搜索 "wood block" 或 "wooden fish"
   - [soundbible.com](https://soundbible.com/) - 免费音效

2. **自行录制**
   - 用手机录制敲击木质物体的声音
   - 用 Audacity 等工具剪辑为短促音效（0.1-0.3秒）

3. **降级方案**
   - 代码已做容错处理，音效文件缺失时小程序可正常运行（仅无声音）
